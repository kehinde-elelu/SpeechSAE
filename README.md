# SpeechSAE

Explore HuBERT speech representations with sparse autoencoders.

This repository contains the educational `undestandingSAE.ipynb` notebook and Speech Scope demo. Portable setup and deployment files are being added.

Based on [AudioSAE](https://github.com/audiosae/audio-sae). Feature interpretations are exploratory; F1465 is a came-associated candidate, not a verified exclusive word detector.
